 ABOUT THE DATA

The people behind the picture.

All 65,437 responses from the 2024 Stack Overflow Developer Survey are retained. A unit contains up to 50 actual records, grouped within the selected category. Its remainder is shown exactly when opened.

Changing the category repacks the units. Their membership can change; each underlying respondent ID stays the same. Unknown answers remain visible.

Alex and YOU are extra markers. AI trend charts use independent 2023–2025 samples; the main crowd always uses 2024. Profiles stay in memory in this tab and disappear on reload.

Alex is a fictional guide and is never added to the survey. These voluntary responses describe a sample, not every developer.
